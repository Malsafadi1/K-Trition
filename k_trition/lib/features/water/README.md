# Water tracking

The current dashboard lets users log water in US fluid ounces, choose common quick amounts, view daily totals, browse history, and delete entries. These prototype entries are stored in memory only and are cleared when the app restarts.

The persistent database API already supports saving, editing, deleting, and querying water entries. The dashboard has not been connected to it yet. See the [database guide](../../docs/DATABASE_GUIDE.md) before wiring the screen to the repository.
