# Daily goals

The current dashboard lets users edit daily calorie and water goals and shows progress for the selected date. In this prototype, goals are held in memory and reset when the app restarts; the same goal values are used as the user browses dates.

The database layer supports goals that take effect on a chosen date, so historical progress can use the goal that applied on that day. This has not been connected to the dashboard yet. See the [database guide](../../docs/DATABASE_GUIDE.md).
